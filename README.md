## GitHub Practice Reflection

1. **What is the purpose of a Git commit?**  
A Git commit saves a snapshot of changes made to the project and creates a record of those changes.

2. **What is the difference between `git push` and `git pull`?**  
`git push` sends local commits to the remote GitHub repository, while `git pull` downloads changes from the remote repository to the local repository.

3. **Why might a development team use branches?**  
Branches allow team members to work on different features or changes without directly affecting the main version of the project.

4. **What part of Git/GitHub was most confusing to you?**  
The most confusing part was understanding the difference between the local repository, remote repository, and branches, especially when switching between them and pushing changes.

5. **How do you think GitHub will help your team manage the course project?**  
GitHub will help our team keep our code organized, track changes, collaborate on different parts of the project, and merge everyone's work into one repository.
